# kering-qq-pages

本仓库用于归档、托管与发布多个独立的 HTML 页面。这些页面各自独立，互不依赖，可作为静态内容进行访问或分发。

## 项目简介

kering-qq-pages 是一个以 HTML 页面归档为主要目标的仓库。仓库中的每个页面均为独立文件，不依赖特定后端服务或数据库，适合直接通过 GitHub Pages 或其他静态托管服务部署。

仓库不针对任何特定网站、域名或服务，仅作为 HTML 资源的存储与展示空间。

## 目录说明

```
kering-qq-pages/
├── index.html          # 根目录主页（如有）
├── pages/              # 存放各独立 HTML 页面的文件夹
│   ├── page-1.html
│   ├── page-2.html
│   └── ...
├── assets/             # 公共资源文件（样式、图片、脚本等）
│   ├── css/
│   ├── js/
│   └── images/
└── README.md           # 本文件
```

- `pages/`：存放各个独立 HTML 页面文件。
- `assets/`：存放页面共用的样式、脚本与图片资源，便于统一管理。

## 页面归档说明

每个 HTML 页面均为独立归档单元，页面之间无耦合关系。新增页面时，请遵循以下原则：

- 页面文件统一放入 `pages/` 目录。
- 页面所需的资源文件（CSS、JS、图片）建议放入 `assets/` 目录，并保持相对路径引用。
- 避免在页面中包含指向外部网站或服务的硬编码链接，除非确有必要。
- 页面标题、内容、样式等均由作者自行决定，仓库仅提供存储与托管。

## 维护说明

- 仓库维护者会定期检查页面完整性，确保资源文件可访问。
- 如发现页面无法正常显示或链接失效，可提交 Issue 反馈。
- 欢迎通过 Pull Request 提交新的独立 HTML 页面，或对现有页面进行优化。
- 提交前请确保页面内容不违反相关法律法规及 GitHub 服务条款。
